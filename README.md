# Healthcare-Analysis

Project Description

This project analyzes healthcare data to understand the relationship between patients' health conditions, lifestyle factors, and doctor visits.

Objectives

- Analyze the distribution of doctor visits.
- Study visits by age and gender.
- Examine illness, health, and reduced physical activity.
- Identify correlations between healthcare factors.

Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

Dataset

Healthcare dataset containing patient information, health conditions, income, and doctor visits.

Results

The analysis uses graphs and a correlation heatmap to identify patterns in doctor visits and health-related factors.

How to Run

1. Open the ".ipynb" notebook.
2. Click Open in Colab or download it and upload it to Google Colab.
3. Run the cells from top to bottom.
